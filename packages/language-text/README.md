Plain text support in Atom
========================================================================
Adapted from TextMate's [`Text.tmBundle`][1]'s XML grammar file, because
the Atom's core `language-text` package is a straight CSON conversion of
TextMate's `plain text.plist`; rewriting it from scratch was easier (and
less painful) than trying to clean up Atom's shitty CSON formatting.

[1]: https://github.com/textmate/text.tmbundle
